# Page d’accueil Prince Palace pour Divi

## Résultat
Créer un fichier HTML autonome, prêt à être collé dans un module Code Divi, sans modifier ni afficher cette proposition dans l’application actuelle.

## Contenu et style
- Reprendre uniquement les textes fournis dans le document Prince Palace, sans ajouter de promesses ou d’informations nouvelles.
- Mélanger l’élégance noire et dorée des captures avec la structure immersive et éditoriale de restaurantchampselysees.fr.
- Utiliser une grande photo fixe en ouverture, sans vidéo.
- Structurer la page autour de la réservation, des deux ambiances, du programme hebdomadaire, des informations pratiques, des questions fréquentes et du pied de page.
- Utiliser les photos et le logo déjà hébergés sur princepalace.fr.

## Compatibilité
- Isoler tous les styles sous une classe dédiée pour éviter les conflits avec Divi.
- Rendre la page adaptée aux téléphones, tablettes et ordinateurs.
- Conserver de vrais liens HTML pour la réservation, le téléphone et la navigation.
- Ajouter des animations légères désactivées automatiquement si l’utilisateur préfère moins de mouvement.

## Livraison
- Fournir un seul fichier `.html` dans les fichiers téléchargeables.
- Inclure dans le fichier une courte note invisible indiquant qu’il faut le coller dans un module Code Divi pleine largeur.
